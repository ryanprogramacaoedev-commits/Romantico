# Romantico

Este projeto é uma página estática em HTML que pode ser publicada e compartilhada publicamente.

## Como deixar acessível em qualquer lugar

### Opção 1: GitHub Pages (mais simples)
1. Crie um repositório no GitHub.
2. Faça upload de todos os arquivos da pasta, incluindo [Index.html](Index.html), os arquivos de imagem e o CSS/JS embutido.
3. Vá em Settings > Pages.
4. Em Source, escolha a branch principal.
5. Salve e aguarde o GitHub gerar a URL pública.
6. A URL ficará algo como:
   `https://seu-usuario.github.io/seu-repositorio/`

### Opção 2: Netlify
1. Acesse https://www.netlify.com
2. Faça login com GitHub.
3. Arraste a pasta do projeto para o Netlify ou conecte o repositório.
4. Ele gera uma URL pública automaticamente.

### Opção 3: Vercel
1. Conecte o repositório no Vercel.
2. Escolha a pasta raiz do projeto.
3. Publique e obtenha a URL pública.

### Link para compartilhar
Depois da publicação, use a URL pública do site e envie para a pessoa.
Exemplo:
`https://seu-usuario.github.io/seu-repositorio/?nome=Luiza&para=meu%20amor`

A página já está pronta para receber parâmetros na URL, como nome e destinatário da mensagem.
